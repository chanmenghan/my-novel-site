# 电商 AI 视频半自动工作流 v1 规格

**适用：** 信息流卖货视频（森物社首饰盒等）  
**生成方式：** 多参考生视频（图锁人/景，视频锁动作情绪，音频借声线）  
**目标：** 有对标、有想法时，不再对着空白发呆；系统吐出「作业包」，人只做选择和验收。

---

## 1. 目标与非目标

### 1.1 要解决的卡点

- 脑海里有画面，但流程太长，不知道先写分镜还是先挂参考。
- 每次手搓提示词：锁脸、禁止原词、实拍质感、负面词，重复劳动。
- 失败原因其实就那几类，却每次整段重写。

### 1.2 v1 要做到

- 5 步向导：丢对标 → 选模板 → 填变量 → 出作业包 → 按失败点一键改提示词。
- 输出可直接粘贴到「多参考生视频」模块的文案。
- 人工仍负责：选对标、确认首帧、确认台词、选 take、投放。

### 1.3 v1 明确不做

- 不自动调用可灵/即梦 API 出片（先把提示词产线跑通）。
- 不自动剪辑、配字幕、配音轨合成（后期仍手剪）。
- 不自动抓取竞品、不自动写全新创意（创意来自对标 + 卖点变量）。
- 不一次生成整支 60 秒电影，默认按 **6～8 秒一条镜头** 出包，多段再手拼。

---

## 2. 用户路径（5 步）

```
[1 导入对标] → [2 选模板] → [3 填变量] → [4 生成作业包] → [5 失败返工]
                     ↑                                        |
                     └──────── 改变量 / 换模板  ←──────────────┘
```

每一步都能保存草稿。第 4 步之后才允许点「复制提示词」。

---

## 3. 输入字段

### 3.1 必填

| 字段 ID | 名称 | 类型 | 说明 |
|---|---|---|---|
| `benchmark_video` | 对标视频 | 文件 | 原对标或动作参考。多参考里通常挂为视频1。 |
| `keyframe_image` | 首帧/关键帧 | 图片 | 人物+场景+产品锁定。多参考里通常挂为图片1。 |
| `template_id` | 模板 | 枚举 | 见第 4 节。 |
| `product_name` | 产品名 | 文本 | 如：森物社实木双层首饰盒 |
| `duration_sec` | 本段时长 | 6 / 8 / 15 | v1 默认 6。 |
| `dialogue` | 本段口播 | 多行文本 | **必须是要说的新词**，不是对标原词。 |

### 3.2 选填（有则质量明显更好）

| 字段 ID | 名称 | 类型 | 说明 |
|---|---|---|---|
| `product_images` | 产品参考图 | 1～3 张 | 盒面、打开内衬、锁扣特写。 |
| `voice_audio` | 声线/情绪参考 | 音频或视频音轨 | 只借声线语速，不借原词。 |
| `cast_notes` | 人物锁定说明 | 文本 | 如：图1女主播，黄工装，身后货架。 |
| `selling_points` | 卖点 3～5 条 | 列表 | 现场改模板必填。 |
| `freebie_line` | 白送/活动句 | 文本 | 如：拍一发三，mini 直接送，不换购。 |
| `realism_preset` | 质感预设 | 枚举 | `phone_live` / `factory` / `product_macro`，默认 `phone_live`。 |
| `shot_role` | 本段在整支片子里的位置 | 开场 / 中段 / 收束 | 影响冲突强度和盘点句。 |

### 3.3 字段校验

- `dialogue` 为空且模板需要开口 → 拦截，提示「先写本段要说的中文，不要让模型跟对标念」。
- `keyframe_image` 为空 → 警告「不锁首帧极易换脸换景」，仍允许继续。
- `selling_points` 少于 3 条且模板 = 现场改 → 警告。
- 口播字数 vs 时长：中文约 **4～6 字/秒**。超出则拆成下一段或提示删句。

## 4. 模板（v1 只做 4 个）

每个模板 = 结构骨架 + 参考绑定规则 + 提示词拼装 + 验收清单。

### 4.1 `host_hook` 女主播开场

**何时用：** 「森物社又放大招啦」这类 6～7 秒开门。  
**结构：** 0 秒就开口，禁止对站发呆。  
**参考绑定：**

| 槽位 | 素材 | 权重含义 |
|---|---|---|
| 图片1 | `keyframe_image` | 人、景、构图 100% 锁定 |
| 音频2 / 视频2 | `voice_audio` 或对标声 | 只借声线、语速、情绪 |

**必须演的情绪（写入提示词）：** 宣布大新闻 + 拍板承诺，直播间劲，不是念广告。

### 4.2 `demand_rework` 现场改 / 交作业

**何时用：** 仿酸奶「提意见 → 收到 → 交作业」。  
**结构（可按卖点条数自动展开）：**

1. 开场授权开喷  
2. 每条卖点：吐槽 → 收到 → 交作业特写  
3. 必须有 1 次「贵 → 不换购直接配」  
4. 盘点全部升级  
5. 结尾「我还有个建议」

**参考绑定：** 图片锁车间/人物；对标视频锁抬杠节奏；产品图锁交作业特写。  
**变量：** `selling_points` + `freebie_line`。

v1 若总时长选 6 秒：只跑「开喷 + 1 个交作业 + 白送句」。完整 30 秒拆成多条作业包。

### 4.3 `conflict_skit` 黄金 3 秒冲突短剧

**何时用：** 机场吵架、当众决裂带货。  
**结构：** 0～0.8 秒先动作（拉扯/拦路）→ 再对白 → 不要对站。  
**参考绑定：** 图锁演员与场景；视频只借吵架火气，禁止原词。

### 4.4 `product_beauty` 产品特写

**何时用：** 木纹、绒面、锁扣、打开 7 合 1。  
**结构：** 慢环绕或推近 + 一道柔和掠光。  
**质感死规则：** 哑光柔光木纹，低反光，无油亮白斑，无盒面噪点，背景可虚、产品必须清。

## 5. 提示词拼装规则（核心）

输出三段，用户可分别复制：

1. **主提示词（中文）**  
2. **主提示词（英文）** — 部分工具英文更稳，v1 都给  
3. **负面词**

### 5.1 固定头（每次都拼，不允许删）

中文逻辑必须包含：

- 严格以图片1为第一帧 / 关键帧，不换人、不换景、不切镜。
- 对标视频 / Mixed 仅参考动作节奏、表情强度、声线情绪。
- **禁止使用参考音视频中的任何原词原句、原口型。这是台词替换，不是配音克隆。覆盖原声。**
- 口型必须对准「dialogue」逐字。
- 竖屏，手机实拍/直播现场感；人脸干净高清无噪点；自然皮肤；同一现场光；接触地面/桌面；轻微手持晃。
- 禁止塑料脸、胶片颗粒、电影摇臂、HDR。

### 5.2 模板中段

按 `template_id` 插入分镜与情绪指令（开场即动、交作业特写、拉扯拦路等）。

### 5.3 变量注入

把 `dialogue` 整段用引号加粗写入，并写「一个字都不能改」。  
`product_name`、`selling_points`、`cast_notes` 写入锁定句。

### 5.4 固定负面词

```
平淡念稿、面无表情、口型对原声、复述对标台词、保留原音频、
换脸、换景、硬切、塑料肤、美颜磨皮、噪点、胶片颗粒、砂纸脸、
油亮镜面、刺眼白斑、抠图硬边、悬浮、过锐、HDR、卡通、字幕烧录
```

### 5.5 质感预设追加

| 预设 | 追加正面 | 追加负面 |
|---|---|---|
| `phone_live` | 直播现场光、手持微晃、口型清晰 | 棚拍、电影感 |
| `factory` | 车间顶灯、货架实拍、环境声可有人走动 | 影棚无尘 |
| `product_macro` | 哑光柔光、木纹清晰、锁扣/绒面材质真实 | 钢琴漆、油亮、盒面噪点 |

## 6. 作业包输出（第 4 步屏幕）

系统生成一份 **Shot Package**，字段如下：

```text
# 镜头 ID：YYYYMMDD-模板-序号
时长：6s
模板：host_hook
多参考挂载：
  - 图片1 = 首帧（身份与场景锁定）
  - 视频1 = 对标（只借动作/情绪）
  - 音频2 = 声线（只借音色语速）
工具设置：
  - 关闭「保留原声」
  - 打开「生成对白 / 重绘音频」
  - 图生视频强度：身份锁定优先（若工具有权重，图 > 视频音）
口播（强制）：
  「……」
主提示词（中文）：……
主提示词（英文）：……
负面词：……
验收清单：见第 7 节
```

支持一键复制四块：挂载说明 / 中文提示词 / 英文提示词 / 负面词。

---

## 7. 验收清单（人过，不自动判片）

生成后必须人工过这 8 条，任何一条否 → 进第 8 节返工：

1. 第一秒是否已经在演，而不是定妆照开口  
2. 人脸是否还是图片1（崩脸/换人）  
3. 场景是否还是图片1  
4. 有口播时，是否在说 **新台词** 而不是对标原词  
5. 产品是否还是我们的盒（锁扣、木色、logo）  
6. 是否像手机实拍（脏噪点、油亮、塑料脸 = 不及格）  
7. 人是否「贴」在背景上（缺接触阴影）  
8. 情绪是否对（开场要冲，交作业要爽，冲突要近）

## 8. 失败返工（一键追加，不整段作废）

界面：多选失败原因 → 「生成下一版提示词」。  
在上一版主提示词 **顶部** 追加对应补丁（越靠前越强），并加对应负面词。

| 失败代码 | 勾选项 | 追加补丁（摘要） |
|---|---|---|
| `wrong_lines` | 念了对标原词 | 台词替换任务；忽略参考里全部对白；口型必须是…… |
| `dead_open` | 开头太静/对站 | 第0秒已在动作/已在喊；禁止先愣 |
| `weak_conflict` | 冲突不够 | 拉扯、拦路、贴脸；冲突优先于站位好看 |
| `face_drift` | 崩脸换人 | 五官发型服装 100% 贴图1；禁止迁移对标人脸 |
| `scene_drift` | 换景 | 背景货架/机场/车间锁定图1 |
| `cutout` | 抠图感 | 同一光源、接触阴影、边缘融入 |
| `noisy_face` | 脸脏、噪点 | 人脸零噪点；不要胶片颗粒 |
| `oily` | 木面油亮 | 哑光柔光；禁止钢琴漆/镜面白斑 |
| `plastic_skin` | 假脸 | 自然毛孔，禁止磨皮 |
| `bad_lipsync` | 口型不对 | 放慢语速仍须对字；逐句口型 |
| `wrong_product` | 盒子长错 | 产品外观严格参考产品图，禁止变成香水瓶/别的盒 |

返工次数写入作业包 `iteration`。超过 3 次提示：换首帧或把 6 秒再拆成 2 段。

## 9. 整支片子如何用 v1 拼

v1 不自动合成终片。推荐一条信息流拆成镜头队列，人工拼接：

| 顺序 | 模板 | 时长 | 例子 |
|---|---|---|---|
| 1 | `host_hook` | 6s | 森物社又放大招啦 |
| 2 | `demand_rework` × N | 每段 6～8s | 格子 / 锁 / 绒 / 实木 各一段交作业 |
| 3 | `product_beauty` | 6s | 打开 7 合 1 + 掠光 |
| 4 | `demand_rework` 收束 | 6s | 盘点 + 拍一发三 + 还有个建议 |

用户可在第 2 步勾选「生成整片镜头队列」，系统按模板输出 **多个作业包**，编号 `01-hook`、`02-grid`、`03-lock`…

## 10. 界面 v1（能画出来就停）

单页，不要后台管理系统。

```
左：素材槽（拖入图/视频/音频，自动编号 图片1 视频1 音频2）
中：模板选择 + 变量表单
右：作业包预览 + 复制按钮 + 失败原因多选
底：验收清单 8 勾
```

空状态文案：  
「先丢对标和首帧，再选这镜是开场、交作业、冲突还是产品特写。」

## 11. 实现优先级

**P0（先能用，表格或 Notion / 飞书文档也能跑）：**

- 4 个模板的提示词骨架（填空）
- 固定头 + 负面词 + 失败补丁库
- 口播字数 vs 时长校验（人工心算也行，文档里写清楚）

**P1（做一个本地页）：**

- 表单 → 拼接 Markdown 作业包
- 一键复制
- 失败多选追加补丁

**P2（以后再说）：**

- 接可灵/即梦
- 自动抽对标首尾帧
- 口型检测、脸相似度
- 素材库（角色资产、盒面角度）

v1 成功标准：**不写代码也能按本文档手搓出稳定提示词**；有代码时只是少一次复制粘贴。

## 12. 示例：女主播开场作业包

**输入：**

- 模板：`host_hook`
- 图片1：车间女主播首帧
- 音频2：6.9s 声线参考
- 口播：森物社又放大招啦！顾客意见一次性全满足！
- 时长：6s
- 质感：`phone_live`

**系统应输出的中文主提示词逻辑（骨架）：**

```
严格以图片1为第一帧，不换人、不换景、不切镜。
女主播五官发型穿搭站位与身后陈列 100% 贴合图片1。
6秒竖屏，直播现场手机实拍，现场光，轻微手持，人脸干净无噪点。
音频2只借声线语速情绪，禁止跟读音频2原词。台词替换，覆盖原声。
开口即说，口型必须是：
「森物社又放大招啦！顾客意见一次性全满足！」
「放大招啦」又喜又冲、音量抬高、微微前倾；
「一次性全满足」拍板、坚定、可点头或摊手。
直播开场，不是念稿。
```

若用户勾选 `wrong_lines` + `dead_open`，下一版在最上方再叠：忽略参考全部对白；第 0 秒已经在喊。

---

## 13. 示例：现场改（6 秒只打一刀）

**输入卖点 1 条：** 锁扣太塑料 → 锌合金锁+两把钥匙，不换购直接配。

**分镜自动收缩为：**

- 0–1s：有意见直接提，现场改  
- 1–4s：吐槽锁扣 → 收到 → 钥匙特写  
- 4–6s：不用换购，出厂就配  

完整五项升级不要塞进 6 秒，拆队列。

## 14. 数据怎么存（可选）

若做 P1 本地页，一条作业包存 JSON 即可，不必上数据库。

```json
{
  "id": "20260929-host_hook-01",
  "template_id": "host_hook",
  "duration_sec": 6,
  "product_name": "森物社实木双层首饰盒",
  "dialogue": "森物社又放大招啦！顾客意见一次性全满足！",
  "realism_preset": "phone_live",
  "iteration": 0,
  "fail_codes": [],
  "refs": {
    "image1": "keyframe.png",
    "video1": "benchmark.mp4",
    "audio2": "voice.mp4"
  }
}
```

角色资产库、盒面多角度属于 P2，v1 只存文件名。

## 15. 验收 v1 本身是否合格

内部试用连续出 **3 条不同类型镜头**（开场、交作业、产品特写），满足：

- 从打开到可复制提示词 < 10 分钟（含填表）  
- 同一失败原因第二次不用重写整段  
- 新人按作业包能挂对参考槽位  

不达标就只改文档和骨架，先不要加 API。


# 剧本模板库

## 都市重生复仇模板

**类型**：都市重生 / 逆袭 / 复仇
**篇幅**：24集 x 3000字
**目标受众**：男性读者为主

**核心爽点**：
1. 信息差碾压（我知道你不知道的）
2. 打脸逆袭（你看不惯我又干不掉我）
3. 实力装逼（低调奢华有内涵）
4. 情感满足（美人环绕、兄弟同心）

**节奏公式**：
- 每3集一个小高潮
- 每6集一个转折点
- 每12集一个大事件
- 大结局必须爽

**开头模板**：
[主角死亡/濒死场景]
[意外重生]
[确认时间线]
[制定计划]
[第一步行动]

**结尾模板**：
[最终决战]
[反派落败]
[正义伸张]
[情感升华]
[展望未来]
